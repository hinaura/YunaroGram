## About

YunaroGram is an unofficial fork of the [Telegram Android client](https://github.com/DrKLO/Telegram), built on top of the original open-source codebase (GNU GPL v2).

This project exists as a personal / hobby build with its own visual identity and application ID:

- **Application ID:** `org.yunaro.messenger`
- **Base project:** [DrKLO/Telegram](https://github.com/DrKLO/Telegram)
- **License:** GNU GPL v2 (same as upstream)

> **Disclaimer:** This is **not** an official Telegram app and is **not** affiliated with, endorsed by, or maintained by Telegram FZ-LLC or its team. All Telegram trademarks belong to their respective owner.

## Building

This project follows the same build process as the upstream Telegram Android client. See the [original repository's instructions](https://github.com/DrKLO/Telegram) for build requirements and setup.
